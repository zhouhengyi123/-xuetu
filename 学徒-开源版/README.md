## 三个真正的卖点

### ① 高考 = 一条能看见的进度条

高考不是"还有 219 天"，而是一段**你正在走的距离**。

```
577 分 · 推算（3/6 科有数据）        目标 620 分 · 还差 43 分
[━━━━━━━━━━━━━━━━━━━━●━━━━━━━━━━━]   57% · 突破阶段
起点 520                              目标 620

  ●  ——●———————●—————————○—————————○
 筑基    提分      突破      冲刺      决战
              攻中档题，把会的变成对的

距高考                                  219 天

各科进度
数学  [━━━━━━━━━━━━━━━━━━━━━━━━━━]  101/150
英语  [━━━━━━━━━━━━━━━━━━━━━━━━━━]  109/150
物理  [━━━━━━━━━━━━━━━━━━━━━━]       72/100
语文  待录入
```

**五个游戏阶段**，每段告诉你现在该做什么：

| 阶段 | 区间 | 该做什么 |
|---|---|---|
| 筑基 | 0-20% | 把基础概念补齐，别急着做难题 |
| 提分 | 20-45% | 按题型专项练，抓稳定分 |
| **突破** | 45-70% | 攻中档题，把会的变成对的 |
| 冲刺 | 70-90% | 压缩失误，稳住已经拿到的 |
| 决战 | 90-100% | 只做三件事：真题、错题、作息 |

**让努力可见**：今天做了事，进度条就动，显示「↑ 今天已让进度条动了 3.0 分」。

### ② 主动式 AI —— 老师先开口

真正的老师不会等学生来问，他会主动找你。

| 类型 | 触发 | 示例 |
|---|---|---|
| 🤔 缺口追问 | AI 了解你 < 45% | 「我想更了解你 —— 现在只有 20%，缺的是：上传试卷」 |
| ⏰ 复习提醒 | ≥3 道题到期 | 「有 3 道题该复习了 —— 今天不复习就会忘」 |
| ⏰ 学习提醒 | 4 天没动静 | 「5 天没动静了 —— 先做 5 道题，做着做着就进去了」 |
| 🎉 进度庆祝 | 完成度 ≥75% | 「你已经走到 84% 了，剩下的是每科再提一点点」 |
| 👋 启动问候 | 前四项都没有 | 「晚上好。距期中考还有 15 天，现在开始不算晚」 |

**设计原则**

- **不打扰** —— 同一类提醒一天最多一次
- **有理由** —— 每条都说清楚"为什么现在说"
- **可执行** —— 不是"加油"，是「去复习」按钮
- **老师口吻** —— 像班主任，不像客服

## 技术架构

```
┌─────────────────────────────────────────────┐
│  界面层  web/（Electron 直接加载）            │
│  侧栏 + 环境光 + 19 个动画                    │
└──────────────────┬──────────────────────────┘
                   │
┌──────────────────▼──────────────────────────┐
│  记忆中枢  shared/memory.js                  │
│  ┌────────┬────────┬────────┐               │
│  │档案记忆│对话记忆│事件记忆│               │
│  └────────┴────────┴────────┘               │
│         ↓ 所有 AI 唯一入口                   │
└──────────────────┬──────────────────────────┘
                   │
      ┌────────────┼────────────┬─────────────┐
      ▼            ▼            ▼             ▼
   快速问答     三合一       Agent       深度辅导
  (DeepSeek)  (TutorHub)  (18工具)   (DeepTutor)
```

**记忆三层**

- **档案记忆** —— 起点、目标、选科、知识点（学生是谁）
- **对话记忆** —— 最近 40 轮（防止重复问、重复讲）
- **事件记忆** —— 做过什么（AI 知道你这几天干了什么）

**离线优先**：Three.js（655 KB）+ MediaPipe（16 MB）全部内嵌，不依赖 CDN。

## 快速开始

### 下载即用（Windows）

去 [Releases](../../releases) 下载，两个版本任选：

| 版本 | 大小 | 包含什么 | 适合谁 |
|---|---|---|---|
| **精简版** | 107 MB | 除深度辅导外的全部功能 | 大多数用户（推荐） |
| **完整版** | 362 MB | 全部功能，含 DeepTutor 深度辅导 | 想要完整功能的人 |

**安装步骤**

1. 下载 `.tar.gz` 文件
2. 用 7-Zip / WinRAR 解压（Windows 自带的不支持）
3. 双击 `学徒.exe`

**首次启动需要填 API Key**（软件不预置任何密钥）。也可以用 WorkBuddy 免费额度。

### 从源码运行

```bash
git clone <your-repo-url>
cd 学徒-开源版
node scripts/setup-vendor.cjs   # 下载第三方库（16 MB，首次需要）
pnpm install
pnpm start
```

### 打包成 exe

```bash
node _build_exe.cjs
```

## 隐私

**所有学习数据只存在你电脑上**（`%APPDATA%/xuetu-app`）

- 人脸画面**只在本地处理**，不上传
- 匿名使用统计**默认关闭**，只有你主动开才上报
- 只发：随机 ID + 启动次数 + 版本号
- **绝不发**：成绩、错题、对话、姓名、学校、IP
