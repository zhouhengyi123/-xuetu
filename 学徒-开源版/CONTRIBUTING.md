# 贡献指南

感谢你考虑为「学徒 · AI 学习系统」做贡献！

## 这个项目的核心原则

**AI 先了解学生，再服务学生。** 不了解之前，不编故事。

任何新功能都要遵守这条线：
- 没有证据就不要给数字
- 拿不准就标"待确认"，别假装确定
- 数据只存在用户电脑上，绝不上传学习数据

## 怎么贡献

### 报告 Bug

开 Issue，写清楚：
1. 你在哪个页面、做了什么操作
2. 期望发生什么
3. 实际发生了什么
4. 软件版本（设置页右上角）

### 提功能建议

也开 Issue，标题写 `[功能]`，说明：
- 这个功能解决什么学习问题
- 为什么现在的做法不够

### 提交代码

1. Fork 并克隆
2. 新建分支：`git checkout -b fix/你的改动`
3. 改完跑一遍回归：`node 跑测试.cjs`（需要先起 `python server.py`）
4. 提交 PR，写清楚改了什么、为什么

## 代码约定

- **不要引入新的 CDN 依赖**——所有资源必须本地化（这个项目是离线优先的）
- **不要破坏既有测试**——151 项断言必须全过
- **改动 AI 相关逻辑时**，确认它仍然遵守"先了解再服务"

## 重点关注的方向

- 估分/复习算法改进
- 更多学科、地区的适配
- UI/UX 细节（这个软件面对真实高中生）
- Bug 修复
