# 用 WorkBuddy 云服务做下载站 —— 可行性与做法

> 2026-10-31 · 基于你已充值的 WorkBuddy 标准版

---

## 一、先说结论

| 你要的 | 可行吗 | 说明 |
|---|---|---|
| **用云服务托管 exe 下载** | ⚠️ 可能不行 | 取决于 WorkBuddy 云服务的存储限制 |
| **用云服务做网站** | ⚠️ 可能不行 | 要看它支不支持静态资源托管 |
| **用云服务做统计接口** | ✅ 已验证可行 | 你的 stats-server 就跑在上面，实测通过 |

**关键区别**：
- 你的 `stats-server.cjs` 是**常驻 Node 进程**，只存 JSON 文件（几 KB）→ 能跑
- 托管 exe（361 MB）是**静态大文件** → 大多数沙箱平台不允许

---

## 二、我不知道的三件事

老实说，以下信息我**无法从你这台机器上查到**，需要你去 WorkBuddy 后台看：

1. **云服务的存储配额是多少**
   - 如果只有几百 MB → 放不了完整版
   - 如果有几个 GB → 可以

2. **是否支持大文件静态托管**
   - 很多沙箱平台限制单文件大小（比如 10 MB）
   - 有些禁止 `Content-Type: application/octet-stream`

3. **是否有流量/带宽限制**
   - 361 MB 的包，10 个人下载就是 3.6 GB 流量
   - 免费额度可能不够

## 三、推荐方案（按可靠性排序）

### 方案 A：GitHub Releases（最标准，推荐）

**为什么推荐**：
- 免费，无流量限制
- 单文件上限 **2 GB**（你的 361 MB 完全够）
- 带下载统计（能看到多少人下）
- 全球 CDN 加速

**做法**：见文末的详细步骤

---

### 方案 B：GitHub Releases + WorkBuddy 做落地页

```
用户访问 https://你的域名/
        ↓
   WorkBuddy 云托管的页面（几 KB HTML）
        ↓
   点「下载」→ 跳转 GitHub Release
```

**好处**：
- 云服务只托管几 KB 的 HTML（肯定够）
- 大文件走 GitHub（不占你额度）
- 页面可以做得好看

**这个方案我有把握可行**，因为：
- HTML 文件很小
- 只做跳转，不传大文件

---

### 方案 C：WorkBuddy 直接托管（需要你先确认配额）

**做法**：把 zip 放进云服务目录，让用户直接下载。

**你需要先去后台确认**：
- [ ] 存储配额有多少？
- [ ] 单文件上限多少？
- [ ] 月流量限制多少？

**如果这三项都够** → 这个方案最简单。

## 五、GitHub Releases 完整步骤

### 第 1 步：创建仓库

1. 打开 https://github.com/new
2. Repository name：`xuetu-app`
3. Description：`学徒 · AI 学习系统 —— 把高考变成一条能看见的进度条`
4. 选 **Public**
5. **不要**勾选 Add a README（我们已有）
6. 点 Create repository

### 第 2 步：上传代码

在桌面「学徒-开源版」文件夹里：

```powershell
cd "$env:USERPROFILE\Desktop\学徒-开源版"

git init
git add .
git commit -m "init: 学徒 AI 学习系统 v1.1.0"
git branch -M main
git remote add origin https://github.com/你的用户名/xuetu-app.git
git push -u origin main
```

> 如果提示要登录，用 Personal Access Token（不是密码）：
> Settings → Developer settings → Personal access tokens → Generate new token
> 勾选 `repo` 权限

### 第 3 步：创建 Release（放 exe 的地方）

1. 进入你的仓库
2. 右侧点 **Releases** → **Create a new release**
3. 填写：
   - **Tag version**：`v1.1.0`
   - **Release title**：`v1.1.0 —— 游戏化进度条 + 主动式 AI`
   - **Description**（可直接复制）：

