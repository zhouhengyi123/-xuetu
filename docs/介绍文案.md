## 和别人不一样的地方

大多数 AI 家教**对你一无所知，却敢给你估分、出题、排计划**。

学徒的做法是：

- 没填问卷 → 不估分，只说「先告诉我你的起点」
- 没传卷子 → 不出题，说「出卷前我需要更了解你」
- 数据不足 → 只给**区间**，绝不用平均分硬凑

**AI 先了解你，再教你。不了解你，它不编故事。**

## 三个核心功能

### 一、高考 = 一条能看见的进度条

高考不是「还有 219 天」，而是一段你正在走的距离。

```
577 分 · 推算（3/6 科有数据）    目标 620 · 还差 43 分
[━━━━━━━━━━━━━━●━━━━━━━━━━]   57% · 突破阶段

  ●  ——●—————●———————○———————○
 筑基    提分    突破      冲刺    决战
            攻中档题，把会的变成对的

距高考                          219 天

数学  [━━━━━━━━━━━━━━━━━━━]  101/150
英语  [━━━━━━━━━━━━━━━━━━━]  109/150
物理  [━━━━━━━━━━━━━━━]       72/100
```

五个阶段，每一段都告诉你现在该做什么：

| 阶段 | 区间 | 该做什么 |
|---|---|---|
| 筑基 | 0-20% | 把基础概念补齐，别急着做难题 |
| 提分 | 20-45% | 按题型专项练，抓稳定分 |
| 突破 | 45-70% | 攻中档题，把会的变成对的 |
| 冲刺 | 70-90% | 压缩失误，稳住已经拿到的 |
| 决战 | 90-100% | 只做三件事：真题、错题、作息 |

今天做了事，进度条会动，还会显示「↑ 今天已让进度条动了 3.0 分」。

---

### 二、主动式 AI —— 老师先开口

真正的老师不会等学生来问，他会主动找你。

| 类型 | 什么时候 | 说什么 |
|---|---|---|
| 缺口追问 | AI 还不够了解你 | 「我想更了解你 —— 现在只有 20%，缺的是：上传试卷」 |
| 复习提醒 | 有题到期没复习 | 「有 3 道题该复习了 —— 今天不复习就会忘」 |
| 学习提醒 | 几天没动静 | 「5 天没动静了 —— 先做 5 道题，做着做着就进去了」 |
| 进度庆祝 | 离目标近了 | 「你已经走到 84% 了」 |
| 启动问候 | 以上都没有 | 「晚上好。距期中考还有 15 天，现在开始不算晚」 |

**设计原则**：同一类提醒一天最多一次，可以关掉，每条都说清「为什么现在说」，而且一定附带一个能点的动作。

### 怎么装

1. 下载 `.tar.gz`
2. 用 7-Zip / WinRAR 解压
3. 双击 `学徒.exe` 就能用

**不需要安装，不需要装 Node / Python，是绿色版。**

首次启动要填一次 API Key（软件不预置任何密钥），也可以用 WorkBuddy 免费额度。

## 隐私

- 所有学习数据只存在你电脑上
- 人脸画面只在本地处理，不上传
- 匿名统计默认关闭，只有你主动开才上报，且只发随机 ID + 启动次数 + 版本号
- 绝不上传成绩、错题、对话、姓名、学校
