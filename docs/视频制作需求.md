# 宣传视频制作需求 · 学徒 AI 学习系统

> 给视频制作方（人或 AI）的完整需求文档

---

## 一、产品是什么

**学徒**，一个面向中国高考生的 AI 学习软件（Windows 桌面应用，Electron）。

### 一句话定位

> 把高考变成一条能看见的进度条。

### 三个核心卖点（按重要性排序）

1. **高考 = 可见进度条** —— 把"还有多少天"变成"走了多少路"，分五个游戏阶段
2. **主动式 AI** —— 老师主动找你，不是等你来问
3. **基本免费** —— 复用 WorkBuddy 积分，不花自己 API 钱

---

## 二、视频要求

| 项目 | 要求 |
|---|---|
| **时长** | 45-60 秒 |
| **比例** | 16:9（1920×1080） |
| **风格** | 苹果发布会风格：深色背景、大字、留白、慢节奏、光晕 |
| **语言** | 简体中文 |
| **字幕** | 全程中文字幕（可选但推荐） |
| **音乐** | 轻电子 / 未来感 / 无歌词（可选） |
| **语音** | 建议无旁白，纯文字 + 画面（苹果风） |

### 视觉基调

- **背景**：接近纯黑（#000）到深蓝（#0a0f1e）的渐变
- **主色**：蓝紫渐变 `#2997ff → #6e5aef → #bf5af2`
- **字体**：无衬线、粗体、大字号、字距收紧（-2px ~ -4px）
- **光晕**：背景有柔和的蓝紫色光斑，模糊半径大
- **截图**：真实界面截图，带大阴影浮起

## 三、分镜脚本（8 幕）

### 第 1 幕｜开场（0-4 秒）

**画面**
- 纯黑背景，中央浮现一个圆角方块 Logo（蓝紫渐变，里面一个字「学」）
- Logo 下方浮出大字：「**学徒**」
- 再下方小字：「AI 先了解你，再教你」

**文案**
```
学徒
AI 先了解你，再教你
```

### 第 2 幕｜痛点（4-9 秒）

**文案**
```
大多数 AI 家教
对你一无所知          ← 渐变色强调
却敢给你估分、出题、排计划
```

### 第 3 幕｜对比（9-15 秒）

**画面**：左右两张卡片对比，左红右绿

**文案**
```
学徒不一样

【普通 AI 家教】              【学徒】
没数据也给精确分数            数据不足只给区间
出题不看你会什么              不够了解你就不出题
点一下「已掌握」就算学会      必须独立做对才算掌握
每个 AI 各说各话              所有 AI 共用一份记忆
```

### 第 4 幕｜高考进度条【核心卖点】（15-28 秒）

**这是全片最重要的一幕，要给足 13 秒。**

**A. 分数进度条（15-20 秒）**
- 标题：「它知道你在 **哪个位置**」
- 下方是真实软件截图：总览页的大进度条
- 截图内容应包含：
```
577 分 · 推算（3/6 科有数据）    目标 620 分 · 还差 43 分
[━━━━━━━━━━━━●━━━━━━━━━━━━]   57%
```

**B. 五个游戏阶段（20-24 秒）**
- 特写五个阶段点，当前阶段（突破）有光圈
```
  ●  ——●———————●—————————○—————————○
 筑基    提分      突破      冲刺      决战
```

**C. 各科进度（24-28 秒）**
- 各科进度条依次填充
```
数学  [━━━━━━━━━━━━━━━━━━━━━━━]  101/150
英语  [━━━━━━━━━━━━━━━━━━━━━━━]  109/150
物理  [━━━━━━━━━━━━━━━━━━━]       72/100
```

**贯穿文案**
```
把高考变成一条能看见的进度条

不是「还有 219 天」
是「你已经走了 57%」
```

### 第 5 幕｜主动式 AI【核心卖点】（28-38 秒）

**A. 标题（28-31 秒）**
```
老师不会等你来问
```

**B. 主动消息条特写（31-35 秒）**
- 模拟软件里弹出的主动提醒：
```
⏰ 有 3 道题该复习了                    [去复习] ×
   按间隔复习的安排，这几道今天不复习就会忘。
   先做题再对答案 —— 只看解析不算会。
```

**C. 五种主动行为（35-38 秒）**
- 五个小卡片依次出现：
```
🤔 我想更了解你   ⏰ 该复习了   ⏰ 5 天没动静了
🎉 你已走到 84%   👋 晚上好
```

**文案**
```
它会主动找你

发现你缺数据 → 主动问
发现错题到期 → 提醒你
发现你几天没动 → 催你
```

### 第 6 幕｜免费（38-43 秒）

**画面**
- 大字「**不花自己的钱**」
- 下方截图展示 WorkBuddy 已启用状态

**文案**
```
不花自己的 API 钱
直接复用 WorkBuddy 积分
```

### 第 7 幕｜其他能力（43-50 秒）

**画面**：4 个功能行依次滑入（图标方块 + 标题 + 灰字）

**文案**
```
不只是聊天

◈  三合一 AI 辅导
    讲题 · 补知识点 · 检查掌握 · 做演示，系统自动选底层

◉  学习状态监控
    本地识别书写 / 阅读 / 听讲 / 思考 / 分心，画面不上传

◎  间隔复习验证掌握
    只看解析不算会 —— 必须独立做对，隔天仍对才算掌握

◇  18 个 Agent 工具
    跑代码 · 画图表 · 做 3D 场景 · 生成动画 · 导出视频
```

### 第 8 幕｜结尾（50-56 秒）

**文案**
```
AI 先了解你
再教你          ← 第二行用渐变

不了解你，它不编故事

[MIT 开源] [本地优先] [隐私保护] [完全离线可用]
```

## 七、关键提示

### 1. 卖点优先级千万别搞错

上一版失败的教训：**花了 40 秒讲"AI 先了解你"，但用户真正在意的是**：
- 高考进度条（游戏化、看得见）
- AI 主动（不用自己找）
- 免费（不花钱）

"AI 先了解你"是**方法论**，不是**卖点**。它可以作为支撑，但不要做主线。

### 2. 多放真实界面

少讲道理，多给操作画面。观众想看到：
- 进度条真的在动
- AI 真的主动弹消息
- 数字真的在变

### 3. 节奏参考

- 前 4 秒必须抓住注意力（Logo + 定位）
- 15-38 秒是黄金段（两个核心卖点）
- 结尾要留 2 秒静止画面（便于截图传播）

### 4. 不要做的事

- ❌ 不要用真人出镜
- ❌ 不要用搞笑音效
- ❌ 不要讲技术细节（Electron、Bayesian 之类）
- ❌ 不要超过 60 秒
