# 估分算法深入研究：方法、偏差与验证设计

> 版本：2026-10-10 · 阶段：**只研究，未改代码**
> 适用：学徒·AI 学习系统（项目2）成绩估算模块
> 目的：给出可实施的算法方案，并明确**哪些结论有证据、哪些只是先验假设**

---

## 0. 先说结论（三句话）

1. **旧算法不能声称"高考等效分准确"。** `_calib.js` 报告的 MAE 0.7pt 是合成数据的产物，
   而且这个数值恰好等于它自己那条混合规则的必然输出（见 §2.4），**不是独立准确性验证**。
2. **教育测量学上，我们目前不具备做正式等值（equating）的条件。** NEAT 等值要求共同锚题与
   双样本；IRT 要求每个题目上百名考生的作答。我们只有**一个学生**。
   因此正确做法是把输出定义为「**先验假设下的敏感性估计 + 不确定区间**」，而不是"高考分"。
3. **浙江口径必须先分清**：语数外按原始分，选考按**等级赋分**（20 个区间、等比例转换，
   依赖当次当科全体考生的卷面分布）。现在代码把选考原始得分率 ×100 当高考分，**口径就是错的**。

## 1. 现状审查：先修数据链，再谈算法

> 以下问题都在生产路径上，不是测试脚本的问题。**算法再准，被重复计数也会错。**

### 1.1 【严重】同一份成绩被计两次

- `js/app.js:3497-3502`（手动导入）：每科同时 `addPaper()` + `addRecord()`，`paperId` 关联，**同一分数写了两份**。
- `js/app.js:4356-4368`（上传识别）：同样同时写 papers 与 records。
- `js/progress.js:101-111`：当该科**没有任何已判对错的题目**时，把 `records` 全部追加进 `perPaper`，
  **没有按 `paperId` 去重**，并且来源硬编码为 `'unknown'`，**丢掉真实来源**（真题被当成未标注）。

**后果（实测推演）**：数学高考真题 100/150、`kind='real'`：
```
paper 侧：factor = 1.00（真题不做折算）
record 侧：factor = 0.72（unknown → 学科基准），且近期权重 2 倍
等效 ratio = (100/150) × (1 + 2×0.72)/3 = 0.54222  →  81.3 分（应为 100）
```
**一旦该科补上任何一道判过对错的题，这些 records 又被整体排除** —— 估分会在"补一题"后
突然跳变。

### 1.2 【严重】保存校正会破坏真实得分

`js/app.js:3309-3319`：
```js
const newScore = round5(Number(paper.fullScore) * right / qs.length);
```
- 忽略**每题分值**（partial credit）：全卷统一按题数平均，语数英里一道大题 15 分和小题 3 分等权。
- **未知（`isCorrect == null`）被当成错**：识别不确定的题直接判错，分数被压。
- 并把重算结果**回写进原始 record**（`hit.score = newScore`），**原始卷面分不可恢复**。

这是**数据破坏**，不只是预测偏差。

### 1.3 六科汇总绕过本地约束

`js/app.js:4643-4651`：
- AI 返回的 `subjectScores` **没有夹到 `[0, maxScore]`**；
- `r.total` 直接采信，**可与六科之和不一致**（模型算错加法就跟着错）。

`js/app.js:4671`：
```js
covered: allSixSubjects(), missing: [], coverage: 6, totalSubjects: 6,
```
- **强制标记为"六科齐全"**，即使 AI 漏科；
- 完全绕过 `js/progress.js:425-429` 的 `current ± [0.85, 1.10]` 夹取与覆盖率约束。

### 1.4 【已修】样式表链接被破坏

统一版本号时正则误伤，`index.html` 三个 `<link>` 变成 `href="=50"`（CSS 全失效）。
→ 本次已修复为 `css/*.css?v=50`。

### 1.5 旧"校准实验"的循环论证

`_calib.js:49-53` 造卷：
```js
const nRight = Math.round(25 * 0.70);   // = 18 → 逐题正确率 72%
score: Math.round(full * 0.70)          // 卷面 70%
```
`progress.js:171` 的口径 `rawRatio = 卷面×0.65 + 逐题×0.35 = 0.70×0.65 + 0.72×0.35 = 0.707`
→ 总分偏高 5.25 分，**"MAE 0.7pt" 正是这条混合规则的固定偏差**。

**结论：该实验只能验证"代码路径通不通"，不能说明预测是否准确。**

## 2. 理论依据（含证据级别）

### 2.1 等值（Equating）——**我们做不到，也不该声称做到**

NEAT（非等组锚题）设计下，两套卷子由**不同考生样本**作答，靠**共同锚题**建立分数转换；
主流方法有 Tucker、Levine（观察分/真分）、链式等百分位等。
来源级别：教科书 / 权威机构技术文档。

- 关键前提：**锚题 + 两个独立样本 + 各自足量样本量**。
- 我们只有：一名学生、若干套卷子、**没有任何共同锚题**。

⇒ **`LLM 判难度=3 档` 绝不能让 `factor=1`，更不能表述为"已完成高考等值"。**
它只是**专家先验**。现算法应更名表述为「**基于先验的敏感性估计**」。

### 2.2 IRT / Rasch——**样本量不足，不适用**

- Rasch（1PL）是最省样本的模型，方法学研究仍建议**上百名考生**才能获得稳定题目参数（±0.5 logit 级别）；
  2PL 每增加一个参数，需要更大样本。
- 我们 n=1 考生 ⇒ **题目难度无法被"校准"，只能被"假设"**。

⇒ **本系统不做 IRT，只做"先验 + 证据更新"，并在界面上承认这一点。**

### 2.3 经典测量理论 / 回归到均值——**必须做收缩**

- 观测分 = 真分 + 误差；样本量越小，观测越向均值回归。
- **经验贝叶斯收缩**：把单个学生的噪声估计向先验收缩
  `θ̂ = w·ȳ + (1−w)·μ_prior`，`w = τ² / (τ² + σ²/n)`
  —— 题少/卷少时 `w` 小，估计自动靠近先验；证据多了才让数据说话。
- 这是**提高期望精度**的标准做法，不是"拍脑袋取中间值"。

### 2.4 能力估计的合理表达方式——**PISA 合理值（Plausible Values）**

大规模测评（PISA）**不输出单一能力点估计**，而是：
- 把能力视为**潜变量分布**，抽取多个合理值；
- 报告**标准误**，用多组合理值计算方差（含测量误差）；
- 分析时对多组结果取平均并合成误差。

⇒ **我们应当输出"区间 + 数据充分度"，而不是一个精确到小数点后 5 位的分数。**
（现界面 `(ratio*100).toFixed(5)+'%'` 这种精度是**虚假精度**。）

### 2.5 主观题与部分得分——**Partial Credit**

多级计分（PCM）适用于作文、解答题、实验探究等多档给分题。
- 用 `isCorrect` 二值化会**系统性低估**主观题得分。
- ⇒ 有 `q.score` 时**必须优先用题目分值**加权，而不是数对错。

### 2.6 预测区间 ≠ 置信区间

对**未来某次考试**的预测，要用**预测区间**（含个体差异 + 测量误差 + 模型误差），
必然**远宽于**对"当前均值"的置信区间。⇒ 预测分必须给区间。

## 3. 浙江高考分数口径（官方）

来源：浙江省教育考试院《浙江省 2022 年高考招生相关政策问答》
https://www.zjzs.net/art/2022/6/19/art_159_7037.html

| 科目 | 满分 | 计分方式 |
|---|---|---|
| 语文 / 数学 / 外语 | 150 | **按卷面得分**计入总成绩 |
| 选考（7 选 3） | 100 | **等级赋分**，起点 40 分 |

**等级赋分规则（20 个赋分区间）**：
以**当次当科全体考生卷面得分**为依据，按事先公布的累计比例划 20 个赋分区间；
区间内按**等比例转换**，四舍五入。

人数比例（%）依次：`1,2,3,4,5,6,7,8,7,7,7,7,7,7,6,5,4,3,2,1`
（第 1、2 名等级合并为 100–97 区间）

赋分区间：`100-97, 96-94, 93-91, 90-88, 87-85, 84-82, 81-79, 78-76, 75-73, 72-70,
69-67, 66-64, 63-61, 60-58, 57-55, 54-52, 51-49, 48-46, 45-43, 42-40`

转换公式（区间内等比例）：
```
(t − t1) / (t2 − t1) = (s − s1) / (s2 − s1)
```
`s` = 卷面得分，`[s1,s2]` = 该区间卷面上下限；`t` = 赋分，`[t1,t2]` = 赋分区间上下限。

**另有保障基数 6.5 万人**：某科赋分人数少于 6.5 万时，按 6.5 万为基数从高到低赋分。

**对本系统的意义**：
1. 选考**不能**用"原始得分率 × 100"当高考分（现 `progress.js:238-239` 正是这么做的）。
2. 正确路径：**原始表现 → 全省百分位（估计）→ 官方 20 区间表 → 赋分**。
   区间边界是**官方给定**的，这一部分是可复现的；**百分位估计**才是需要假设的部分。
3. 语数外可用原始分口径，但仍需难度折算。

## 5. 新算法方案

### 5.0 分层结构

```
① 证据层（数据链修复）
   每份卷子 → 一条证据，按 paperId 唯一化
   题目层：优先 q.score / fullScore_sub；无则用 isCorrect
   输出：观测 θ̂_i（logit）+ 不确定度 σ_i

② 校准层（先验 + 收缩）
   难度偏移 δ_i（先验，来自逐题难度档）
   来源偏移 ρ（先验，学科 × 来源）
   时间权重 w(t)（指数半衰期）
   → 分科能力估计 θ̂_subject ± SE（经验贝叶斯收缩）

③ 口径层（分科不同）
   语数外：θ → 高考等效得分率 → 分（原始分口径）
   选考：θ → 百分位 → 官方 20 区间 → 赋分（等级分口径）

④ 输出层（区间 + 充分度）
   current ± 区间、projected ± 预测区间
   数据充分度分级（样本量/难度覆盖/来源覆盖）
```

### 5.1 能力尺度：用 logit 而不是百分比

得分率是**有界**的（0~1），直接加权平均会被边界压缩。改用 logit：
```
θ = ln( p / (1 − p) )          p = 卷面得分率（经覆盖率调整后）
p = 1 / (1 + e^(−θ))           反变换
```
好处：可加、可做贝叶斯更新、天然处理边界。

### 5.2 单份卷子的观测与不确定度

```
p_i   = 该卷经"题目层覆盖率"调整后的得分率
θ_i   = logit(p_i)
n_i   = 该卷有效题目数（去重后）
σ_i²  = p_i(1−p_i) / n_i  在 logit 尺度上近似为  1 / (n_i · p_i · (1−p_i))
```
题目越少，σ_i 越大 → 自动降低该卷话语权。

### 5.3 校准偏移（全部标注为先验）

```
θ_i^cal = θ_i + δ_i + ρ_sub,src
δ_i = k_d · (3 − d_i)      d_i = 逐题难度档(1~5, 3=高考平均)；k_d ≈ 0.20 logit/档
ρ   = 来源偏移（对数尺度）：real 0, mock 0, school −0.05, photo −0.15, homework −0.30 …
```
> ⚠️ `k_d` 与 `ρ` 都是**先验参数**，必须：
> (a) 在设置里可调；(b) 参与敏感性分析；(c) 界面标注"假设，非实测"。

### 5.4 时间权重

```
w_i = 0.5 ^ (Δt_i / H)      H = 半衰期（默认 120 天，可配）
```
比现有"最早 1 倍 → 最新 2 倍"更合乎"遗忘/水平变化"的假设。

### 5.5 经验贝叶斯收缩（核心新增）

```
精确度  prec_i = w_i / σ_i²
ȳ       = Σ(prec_i · θ_i^cal) / Σ prec_i
SE²     = 1 / Σ prec_i
τ²      = 学科间/历史方差（从数据估计；不足时用默认 0.6²）
w_shrink = τ² / (τ² + SE²)
θ̂_sub  = w_shrink · ȳ + (1 − w_shrink) · μ_prior_sub
SE_sub = sqrt(w_shrink · SE²)
```
- 证据少 → `SE` 大 → `w_shrink` 小 → **靠近学科先验**（不再被 3 道题带着跑）
- 证据多 → 让数据说话
- **最大学科先验**：用已录入的起点分（问卷 `examScore`）或全省平均得分率，
  而不是凭空写死。

### 5.6 输出分数（分科口径不同）

**语数外**：
```
p̂ = 1/(1+e^(−θ̂))          # 高考等效得分率（学过的范围）
score = p̂_adjusted × maxScore
区间 = (p̂_low, p̂_high) 由 θ̂ ± 1.96·SE 反变换得到
```

**选考（浙江口径）**：
```
percentile = Φ( (θ̂ − μ_cohort) / σ_cohort )     # 需要"考生群体分布"假设
赋分 = officialBandTable(percentile)            # 官方 20 区间，按区间等比例
```
- **区间边界用官方表**（可复现、可审计）；
- **群体分布 `μ_cohort, σ_cohort` 是假设**，必须在界面上标明；
- 输出建议给**档位区间**（如"约 82–85 分"），不装成精确值。

### 5.7 覆盖率：在题目层生效，不在总分上再乘一次

现算法 `ratio × coverage` 有个隐含假设：**未学章节的题在高考里也一定出现且你一定不会**。
更合理的是在**证据层**处理：
```
每道题：
  若该题知识点 ∈ 已学 → 计入观测
  若 ∈ 未学 → 视为"当前拿不到分"，计入观测（isCorrect=false 的等价）
未判定的整卷：按覆盖率折算有效题目数 n_eff = n × coverage
```
这样：
- 不会与"题目正确率"重复相乘；
- 学完新章节后，估算会**自然**上升（因为那些题从"必错"变成"待观测"）。
- **仍需显示**覆盖率来源（AI 折算 / 本地匹配 / 未填）。

### 5.8 预测（高考时）

保持"边际递减学习曲线"，但：
```
headroom = max − current
gain = headroom × k × learnability × (1 − e^(−hours/τ)) × trendAdj
```
- 参数 `k, τ` 现状为拍定值 → 应**显式参数化 + 敏感性区间**；
- **预测区间**：
```
SE_proj = sqrt(SE_sub² + SE_model² + SE_future²)
```
  其中 `SE_model` 由 `k/τ/ρ/k_d` 的参数不确定性传播（蒙特卡洛 200 次即可）；
- **不给单点**，显示 `预测值 [下界, 上界]`。

### 5.9 数据充分度分级（替代假的"置信度"）

现 `confidence = 1 − e^(−n/30)` 只数题目，**不看难度覆盖与来源覆盖**。改为三维：
```
充分度 = f(有效题目数, 判过难度的卷数占比, 来源多样性)  → 低/中/高
```
并据此决定：
- 低 → 只显示区间、不显示单点；提示"再上传 N 份卷子"
- 中 → 显示区间 + 单点，标注"参考"
- 高 → 显示区间 + 单点

## 6. 验证设计（关键：必须独立）

### 6.1 三条铁律

1. **不许在同一批数据上既调参又验证**（旧 `_calib.js` 的错）。
2. **合成数据只能验代码路径**（边界、去重、单位），**不能声称精度**。
3. **真实精度只能靠"前瞻回溯"**：记录预测 → 学生后来真考 → 比对。

### 6.2 测试矩阵

| 维度 | 用例 |
|---|---|
| 难度 | 全程 3 档 / 全 1 档 / 全 5 档 / 混合 |
| 卷长 | 3 题 / 10 题 / 25 题 / 整卷 |
| 部分得分 | 全对错二值 / 有题分（partial credit） |
| 覆盖 | 100% / 60% / 未填 |
| 重复 | 同题 1 遍 / 3 遍 / 5 遍 |
| 时间 | 集中 1 周 / 分散 6 个月 |
| 样本 | 1 卷 / 5 卷 / 20 卷 |
| 来源 | real / mock / school / homework 混合 |
| 缺失 | 缺满分 / 缺来源 / 缺难度 / 缺题分 |
| 异常 | 超出满分 / 负分 / 未来日期 / 同 paperId 双写 |

### 6.3 指标

- **MAE / RMSE**（分科、总分）
- **有符号偏差**（区分系统性高估 vs 低估）
- **区间覆盖率 PICP**：95% 区间应真的覆盖 ~95%（**这是"诚实"的核心指标**）
- **校准曲线**：预测分位 vs 实际分位
- **稳定性**：加一道题 / 删一份卷，估算变化幅度（现算法会跳变，必须测）
- **基线对照**：① 朴素平均 ② 旧算法 ③ "起点分不动" ④ "全省平均" —— 新算法必须**打得过**这些

### 6.4 反作弊检查

- 参数 `k_d / ρ / k / τ / H` 做**敏感性扫描**：若结论在合理范围内大幅翻转 → 说明该结论不可信，界面必须显示区间。
- 留一法（leave-one-paper-out）：逐个剔除卷子重估，观察方差。

### 6.5 真实精度如何获得（诚实路径）

```
现在：记录每次估算（时间戳、输入、输出、区间）
将来：学生参加真实模考/高考 → 录入实际分
比对：命中率、误差、区间是否覆盖
```
**在拿到真实回溯数据之前，界面上不得出现"准确率 XX%"这类表述。**

## 7. 实施分期

| 期 | 内容 | 风险 |
|---|---|---|
| **P0** | 数据链修复：paperId 去重、保留 source、partial credit、校正不再回写破坏原始分、AI 结果夹取 | 低（不改口径，先修 bug） |
| **P1** | 证据层重构 + 不确定度（σ_i）+ 时间衰减 | 中 |
| **P2** | 经验贝叶斯收缩 + 充分度分级 + 区间显示 | 中 |
| **P3** | 浙江选考赋分口径（官方 20 区间） | 中高（需群体分布假设） |
| **P4** | 预测区间 + 参数敏感性（蒙特卡洛） | 中 |
| **P5** | 前瞻回溯数据收集（长期） | 低 |

**P0 必须先做**：否则 P1 之后的所有估计都建立在被污染的输入上。

## 10. 一页速览（给决策用）

```
能不能做等值？       不能（无锚题、单样本）
能不能用 IRT？       不能（n=1，题目参数无法校准）
那能做什么？         先验假设 + 证据更新 + 不确定度 + 收缩
最该先修什么？       数据链（重复计数 / partial credit / 校正破坏原始分）
输出该长什么样？     "现在 ≈ 475 [455, 495] · 充分度：中"，而不是 475.12345
选考怎么办？         百分位 → 浙江官方 20 区间赋分（区间边界可审计，群体分布要标注假设）
怎么证明变准了？     前瞻回溯 + 区间覆盖率 + 打得过朴素基线
现在能声称精度吗？   不能。合成数据不算数。
```
