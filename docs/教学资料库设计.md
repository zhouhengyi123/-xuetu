## 一句话

内置 92 条教学经验 + 158 道题，但**每次只注入 1~3 条**（平均 95 字）。

## 为什么不用开源 RAG

调研过 learn-anything / courseweave / base-rag 等，它们都依赖向量数据库 + embedding 模型。
这个项目是**零依赖、离线可用的桌面应用** —— 引入一整套 RAG 会破坏「双击就能用」这个核心特性。

本机资料量在几 KB ~ 几 MB 之间，用「中文二元组 + 关键词 + 科目过滤 + 重要度」打分完全够用，且完全离线。

---

## 检索的三级门槛（核心）

中文二元组分词有个致命问题：**太容易偶然命中**。
比如「楞次定律方向」会把「欧姆定律」带出来 —— 因为都有「定律」二字。

所以设了三道关：

### ① textHit === 0 剔除
不能只靠「同科 +10 分、重要度 +3 分」混进来。
实测：问题目「量子纠缠」时会返回 3 条语文经验，纯噪声。

### ② 必须有强信号
标题命中、标签命中，或正文命中 ≥2 个不同二元组。
单个词偶然撞上不算。

### ③ STOP_TOKENS 过滤
`定律 / 分析 / 判断 / 方向 / 问题 / 方法 / 学生 / 老师 …` 这些词几乎出现在
所有教学资料里，命中它们不能说明相关。

### 效果对比

| 指标 | 改造前 | 改造后 |
|---|---|---|
| 无关提问返回 | 3 条噪声 | **0 条** |
| 平均注入长度 | 443 字 | **95 字** |
| 最大注入长度 | 不限 | 444 字 |

## 注入点只有两处

```
web/js/app.js  →  persona()          ← LLM.setPersona 的唯一来源
shared/memory.js → Memory.context()  ← 深度辅导 / Agent
```

改这两处，**快速问答 / 出卷 / 批改 / 规划 / 估算 / 答疑全部生效**。
不要在各个 AI 里各写一遍，否则迟早不一致。

## 题库质量的两条硬要求

### 答案分布不能泄露规律

自查发现过：D 选项只占 3%（4/124）。学生做几十道就会发现「选 D 多半错」，
那是在训练猜题，不是解题。

修法：**只调整纯数值/纯单位选项的题**（语义可互换），文字选项的题一律不动。
脚本会记住正确答案原文，移位后校验新位置确实是那段文本，不一致就跳过。

### 难度要能配出整套卷

原来 hard 只有 8 题，想出 10 道难题只能给 4 道。
补充后：hard 22 / easy 24 / normal 112。

## 踩过的坑

### ① App.ask 没有导出

`web/js/app.js` 里的 `ask()` 是内部函数，**没在 return 里**。
测试时调 `App.ask(...)` 全是 `undefined`，等于什么都没测 —— 却还以为「没生效」。

正确测法：

```js
// 拦截 fetch，抓 chatRaw 真正发出的 messages
// 关键：必须带 _providerOverride，否则会走 WorkBuddy 分支，fetch 根本不被调用
await LLM.chatRaw([{ role:'user', content:'...' }], {
  maxTokens: 50,
  _providerOverride: { provider:'deepseek', apiKey:'k', model:'m', baseUrl:'https://x/v1' }
});
```

还要先设 `window.__teachQuery`，因为 persona() 靠它知道这次问什么。

### ② 按 `},` 找条目结尾会误删

删重复条目时用「从匹配行找到 `},` 作为结束」的方式，
但**正文里本身含 `},`** —— 一次删掉了 200 行，文件损坏。

正确做法：解析 JS 数组 → 过滤 → 重新序列化。**不要对源码做文本级增删**。

### ③ 分段阈值试了三轮

文本按空行分段时，合并阈值：1200 → 80 → 30 才合理。

- 1200：三段正常教学笔记（63~91 字）被合成一条，检索时整条进 prompt，带进无关内容
- 80：73 字的第 2 段和 63 字的第 3 段仍被合并
- 30：只有「注意：」「小结：」这类过渡句才合并 —— 这才是对的

**空行是作者的语义边界**，不该轻易合并。

### ④ process.cwd() 找运行时是隐患

`deeptutor-runtime.cjs` 原来有个候选路径是 `process.cwd()/runtime/deeptutor`。
用户从任意目录启动 exe，就会去捡那个目录下的 runtime。
精简版本该「跳过」，却因 cwd 恰好指向含 runtime 的目录而硬启动并报错。

打包态只认 `resources/`。

### ⑤ 题目本身会出错

写过一道「f(x)=ln x - ax 在 (0,+∞) 单调递减求 a 范围」——
这个条件其实**无解**（1/x 在 (0,+∞) 无上界，不存在这样的有限 a）。
改成 `[1,+∞)` 才有解。

还有一道自由落体动量题，h=10m 时 p≈28.3，选项里没有这个值。
改成 h=5m 使 v=10、p=20，自洽。

**加题后必须自己算一遍**，不能想当然。
